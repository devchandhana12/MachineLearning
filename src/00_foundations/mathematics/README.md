# Start here: mathematics for machine learning

Read this section before the algorithm tutorials. The chapters build from individual numbers to vectors and matrices, the same structures used to represent features and model parameters in the code.

## Study order

1. [Scalars, vectors, and dimensions](01_scalars_vectors_dimensions.md) — notation, coordinates, and shapes.
2. [Vector addition and subtraction](02_vector_addition_subtraction.md) — combining and comparing vectors.
3. [Scalar multiplication, magnitude, and norms](03_scalar_multiplication_magnitude_norms.md) — scaling vectors and measuring their size.
4. [Dot products and angles](04_dot_product_and_angles.md) — weighted sums, similarity, and the core operation behind linear models.
5. [Linear combinations, span, and independence](05_linear_combinations_span_independence.md) — how vectors combine and when features carry overlapping information.
6. [Matrices, shapes, and operations](06_matrices_shapes_operations.md) — organizing many observations and features for vectorized computation.

## What to study alongside these chapters

Before gradient-based models, review basic algebra, powers, exponentials, and logarithms. Then study:

- **Calculus:** slopes, derivatives, partial derivatives, the chain rule, and gradients. These explain how linear and logistic regression parameters are learned.
- **Probability and statistics:** averages, variance, probability, conditional probability, and likelihood. These explain classification probabilities and cross-entropy.
- **Evaluation:** read [Model Evaluation](../model_evaluation.md) to understand data splits and metrics before comparing models.

Some calculus and probability explanations are already included in the [linear regression notes](../../02_linearRegression/notes.md) and [logistic regression notes](../../03_logisticRegression/notes.md). The standalone chapters in this folder currently focus on linear algebra.

Continue in the order in the repository README: linear regression, multiple linear regression, logistic regression, softmax regression, decision trees, and random forest.
