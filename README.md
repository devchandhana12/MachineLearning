This repository focuses on core Machine Learning and Applied AI concepts, with implementations and experiments around **Linear Regression, Multivariate Regression, Logistic Regression, Softmax Classification, Decision Trees, data preprocessing, and model evaluation**.

It also covers broader Applied AI areas including **Transformers, RAG, AI Agents, Fine-Tuning, and AI System Design**, with emphasis on understanding how models work, how they are implemented, and how they fit into production systems.
